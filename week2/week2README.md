# Стартап в информационных технологиях

## Практическая неделя 2 · Хостинг продающего сайта (лендинг)
Практики 3–4 · 08.09

**Проект:** Разработка веб-сервиса для совместного прослушивания музыки на основе стартап-проекта «TrackTribe»  
**Авторы:** Амини Аким и Меджидов Заур · группа ЭФБО-04-23

---

### Задание

Разработать одностраничный продающий сайт (лендинг) продукта и разместить его на хостинге. Лендинг должен доносить УТП, показывать продукт и вести пользователя к целевому действию — созданию комнаты.

### Что сделано

Собран лендинг TrackTribe в айдентике недели 1 (палитра «пыльная роза», Playfair Display / Inter / JetBrains Mono, знак-нота). Структура:

1. **Первый экран** — слоган «Хорошая музыка. Общий ритм.», УТП, карточка «Создать комнату / Войти в комнату» (ник + код).
2. **Возможности** — синхронность, локальные файлы, вход по QR/коду, псевдоним, RU/EN и три темы, панель «Племя».
3. **Как это работает** — три шага: создать → позвать → слушать вместе.
4. **Сценарии** — расстояние, семейный архив (записи близких), свой круг.
5. **Живое демо** — комната с кодом, QR и приглашением; загрузка локального файла и воспроизведение в браузере.
6. **Сравнение** — TrackTribe против Spotify Jam, Rave, Discord по проверяемым признакам.
7. **FAQ и финальный CTA** — снятие возражений и повторное целевое действие.

Функциональность лендинга:
- форма создания/входа генерирует код комнаты и открывает демо с QR-приглашением;
- демо воспроизводит локальные аудиофайлы пользователя (в браузер, без отправки на сервер) и встроенные треки;
- переключение RU/EN и светлой/тёмной/системной темы, состояние сохраняется;
- адаптивная вёрстка, видимый фокус, поддержка prefers-reduced-motion.

Технически: статический `index.html` (HTML + CSS + JS в одном файле), без сборки и сторонних JS-зависимостей; шрифты — Google Fonts. Подходит для GitHub Pages, Netlify, Vercel или любого статик-хостинга.

### Хостинг (GitHub Pages)

1. Репозиторий → загрузить `week2/index.html`.
2. Settings → Pages → Deploy from a branch → `main` · root → Save.
3. Ссылка вида `https://НИК.github.io/РЕПО/week2/` → в таблицу, колонка **08.09**.
4. Альтернатива: перетащить папку `week2` в Netlify Drop — ссылка сразу.

Для боевого лендинга: в `index.html` задать `APP_URL` (адрес приложения) — форма будет вести в реальный TrackTribe с параметрами `room` и `nickname`. Пока `APP_URL` пуст, форма открывает демо на странице.

### Проверка

- Создание комнаты: ник → код → демо → QR и ссылка-приглашение.
- Вход по коду: валидация формата (8 символов, 0–9 A–F).
- Демо: play/pause, перемотка, громкость, загрузка файла, переключение треков.
- Темы и языки переключаются и сохраняются; мобильная версия без горизонтального скролла.
