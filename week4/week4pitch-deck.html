ядро: Beatsync, MIT — подтвердить

NTP-подобный обмен метками времени поверх WebSocket; клиент выравнивает позицию воспроизведения с точностью до миллисекунд.

2. P2P-передача

WebRTC

Файл идёт напрямую между браузерами (WebRTC DataChannel). Сервер не видит содержимое — ниже трафик и нет хранения чужих файлов.

3. TURN-fallback

допущение ≈15%

Для симметричного NAT — план: coturn на том же VPS (трафик безлимитный). Доля relay-сессий ≈15% — допущение, будем измерять на публичном пилоте.

Стек ядра Beatsync: Bun (HTTP+WebSocket) + Next.js + TypeScript, NTP-inspired sync, MIT (github.com/freeman-jiang/beatsync). Происхождение ядра TrackTribe — допущение, подтвердить и зафиксировать в репозитории/NOTICE.

01 · Контент 0 ₽ · мес 2

Авторские права на музыку

Только личные файлы участников; каталога нет; аудио не хранится на сервере (P2P). Оферта возлагает ответственность на пользователя + процедура takedown. Юрконсультация — университетская юрклиника.

02 · 152-ФЗ 0 ₽ · мес 1 · проверено

Персональные данные (РКН)

Минимум данных: ник, IP, cookie по согласию; аккаунтов нет. Политики опубликованы. Уведомление РКН обязательно до начала обработки (с 01.09.2022, 266-ФЗ) — подаём через электронную форму.

03 · Отказоустойчивость 200 ₽/мес · допущение

Один провайдер / сервер

Ежедневные дампы + снапшоты; резервный провайдер готов к переключению. Реальный прецедент: кибератака на Beget 02.11.2026 с массовым восстановлением — поэтому бэкапы и мультипровайдер заложены с 1-го дня.

Допущения команды (помечены в деке) 8 допущений
1. Бэкапы 200 ₽/мес — уточнить по тарифу снапшотов провайдера.
2. Доля TURN ≈15% — доля relay-сессий, измеряем на пилоте.
3. Сегментация — группы = аудитория ÷ 3; дистанционный сценарий 20%.
4. Траектории роста — динамика подписок по 3 сценариям (конс./баз./опт.).
5. Состав Pro — 25 уч. / 100 треков / без лимита времени (предложение; цена 150 ₽ из кода).
6. Открытое ядро — Beatsync (MIT), подтвердить и зафиксировать в NOTICE.
7. Ставка НДС 22% — в комиссии эквайринга (2026); при 20% вклад меняется <0,1%.
8. Рассинхрон ±100 мс — целевой ориентир, будет измеряться индикатором Sync.

Принцип презентации: ни одной выдуманной метрики пользователей. Спрос — гипотеза с планом валидации на пилоте. Каждая цифра запроса сходится с финпланом и юнит-экономикой.
