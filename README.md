### 🛠 О проекте

**TrackTribe** — веб-сервис для совместного прослушивания музыки. 
Этот репозиторий служит единой базой знаний для команды и хранилищем артефактов разработки.

<br/>

<details>
<summary><b>🗒 Условные обозначения коммитов</b></summary>
<br>
Для удобства навигации по истории изменений в начале сообщений используются короткие префиксы:
<br><br>
• <b>feat</b> — добавление новых файлов или материалов (например, новой недели)<br>
• <b>fix</b> — исправление ошибок или опечаток<br>
• <b>docs</b> — изменения, касающиеся только документации (например, этого README)<br>
• <b>chore</b> — технические правки (настройки, очистка лишних файлов)
</details>
